Methods, CSV format & interpretation +

Bring your predictions

Use a UTF-8 CSV with y_true (0 or 1) and y_score (probability from 0 to 1). Optional patient_id values must be unique. Other columns become subgroup selectors: use categorical values such as age bands, with at most 30 distinct values per column. Maximum: 50,000 patients and 8 MB.

patient_id,y_true,y_score,age_group
001,1,0.82,65+
002,0,0.14,18–39

How we calculate

Use independent, held-out predictions with one row per patient. The tool cannot verify train/test leakage or independence. Repeated encounters require a different uncertainty method. Choose operating thresholds using validation data and the intended use, before assessing final test performance.

Local by design

Your CSV is processed by the Python server on this computer. No external services, analytics, or fonts are called. Data is kept in process memory; the recent bootstrap cache is cleared when the server stops. Exported HTML contains aggregate results, including subgroup labels, and no raw patient records.

This is a research and educational evaluation tool. It does not provide clinical advice or validate a model for patient care.
